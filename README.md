# Airline Delay Prediction – Machine Learning Assignment

## Overview
This repository contains the implementation for a machine learning assignment focused on predicting airline delays. The project is divided into two main parts: data preprocessing and model training.

## Project Structure
- **Part A – Data Preprocessing**
  - Data cleaning and handling of missing values
  - Feature selection and transformation
  - Data encoding and scaling
  - Train–test data splitting

- **Part B – Model Training and Evaluation**
  - Implementation of regression-based machine learning models
  - Model training using preprocessed data
  - Performance evaluation using RMSE and related metrics
  - Comparison of model performance

## Tools and Libraries
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib / Seaborn (for evaluation and visualization)

## Contribution Note

- **Part B (Model Training and Evaluation)** was implemented as an individual contribution.
